🔧 Основной функционал
Общие возможности
👤 Регистрация и вход (роли: пользователь / админ)

🍽 Управление меню (добавление, удаление блюд)

📦 Работа с заказами (создание, изменение, удаление)

📋 Просмотр заказов по пользователям и фильтрация по статусам

💾 Сохранение и загрузка данных через JSON

🧩 Использование DTO между слоями

🧪 Частичное покрытие JUnit-тестами

v1.0.0 — Консольная версия
Простое CLI-меню

Взаимодействие через команды

Один JAR, без сети

🌐 Swing-интерфейс — формы, таблицы, кнопки
